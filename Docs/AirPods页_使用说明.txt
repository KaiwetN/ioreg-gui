  IORegistry 查看器 · AirPods 页使用说明
════════════════════════════════════════════

【这是什么】
本工具主体是 IORegistry 只读可视化（侧边栏「全部设备 / IORegistry」）。
本文档说明其中的「AirPods Pro」页 —— 读取 AirPods 耳机与充电盒的
深度电池健康数据（Apple 从未在 macOS 上提供这个功能）：

• 实时电量 —— 盒 / 左耳 / 右耳三环表（15 秒自动刷新）
• 循环计数 —— 左右耳独立计，完整充放电周期 +1
• 电池容量 —— 当前满充实测容量（新机约 46 mAh）
• 容量退化曲线 —— 固件内置的容量标定里程碑连线
• 关机事件历史 —— 每次断电时电量计 SOC / 电压 / 温度
• 充电吞吐热力图 —— 充电习惯画像（电量段 × 温度段）
• 解读报告 —— 自动生成的中文分析（所有指标白话解释）

【系统要求】
• macOS 14.0 或更高（Intel / Apple Silicon 通用）
• AirPods（需连接过这台 Mac）

【首次运行（重要）】
1. 解压得到「IORegistry 查看器.app」
2. 因为本工具未经过苹果公证收费签名，首次打开：
   右键点击 App → 「打开」 → 再点「打开」
   （如果仍提示无法验证，在终端执行：
     xattr -cr 后面跟App路径，或把App拖到 Applications 后再试）
3. 打开后默认在「实时状态」页，就能看到三环电量
4. 想看循环计数/退化曲线：切到「电池健康」页 →
   点「安装免密授权」→ 输入一次管理员密码 → 完成
   （会安装一条仅限本工具的免密规则，随时可移除）

【数据刷新频率说明】
耳机只在「充电会话结束 / 放回盒子 / 每日翻转」时上报健康数据，
所以循环计数这类数值一天变几次是正常的，不是软件卡了。
顶部橙色的「数据最后上报时间」= 数据新鲜度。
给耳机完整充一次电后再刷新，就能看到循环计数 +1。

【卸载】
• 直接删除 App
• 终端执行（移除免密规则）：
  sudo rm -f /etc/sudoers.d/airpods-health /usr/local/bin/airpods_copy.sh
• 可选（清除本地健康缓存）：
  rm -rf "$HOME/Library/Application Support/IORegistryViewer"

【隐私】
本工具只读取本机已有的数据，不上传任何信息。
（系统自身的 analyticsd 会按苹果的常规策略聚合上报，与本工具无关）

—— 数据来源：耳机固件 BatteryHealth 指标逆向分析
